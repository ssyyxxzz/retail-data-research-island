# 牵牛花亏损订单每日导出与处理

- 原配置状态：启用
- 调度时间：06:15（Asia/Shanghai），准确规则以配置为准。
- 模板默认状态：暂停，不注册、不执行任务。
- 配置：[automation.example.toml](automation.example.toml)

## 流程正文（脱敏）

每天06:15（Asia/Shanghai）执行牵牛花亏损订单处理。工作目录为 ${LOCAL_PATH_003}。

一、下载与日期
每天处理当前日期前两天（T-2）的完整单日数据。下载由Windows定时任务 QNH-Independent-API-loss 调用牵牛花接口执行，入口为 ${LOCAL_PATH_018} -Group loss；不逐页点击网页。后台隔离Chrome端口9223只承载登录会话和签名。先检查当日本地接口记录、进程及实际Excel；同一程序运行中则等待，禁止重复进程或重复提交。只接受运行日创建并通过日期、字段、SKU和门店范围校验的文件。两份原始文件保存到 ${LOCAL_PATH_038}；财务文件以“导出财务分析订单数据”开头，订单商品文件以“导出订单商品明细”开头。没有当日有效来源且程序未运行时才执行入口；失败明确报告，不改回页面操作。

二、清洗
财务源可能含历史记录，必须先严格筛选“下单时间”为T-2，再统计目标日期原始行数和“收入=-”行数并删除。字段按合并两行表头名称匹配，配送费合计=三方配送费+配送服务费。删除收入“-”后、任何统计前，按规范化完整名称精确排除：示例零售门店（示例门店〈07〉）、示例零售门店（示例门店〈13〉）、示例零售门店（示例门店〈56〉）、示例零售门店（示例门店〈35〉）、示例零售门店（示例门店〈53〉）、示例零售门店（示例门店〈48〉）；兼容半角/全角括号和两侧空格，禁止模糊匹配。

三、主工作簿
亏损订单明细筛选“渠道名称=美团闪购且线上毛利<-3”，按确认模板计算配送费合计、活动、定价、原因归属。亏损商品明细取所有亏损订单编号对应的全部商品，不按35%筛选门店。最终文件为 ${LOCAL_PATH_039}，固定7个Sheet及顺序：汇总、亏损订单明细、Sheet3、亏损商品明细、Sheet5、Sheet2、Sheet1；Sheet3和Sheet5隐藏，其余可见；格式以${REFERENCE_DATE_013}最终样例为准。Sheet2优先复制 ${LOCAL_PATH_040}；缺失时使用最近一期已核验工作簿的Sheet2。Sheet1按亏损商品门店与Sheet2门店编码交集，从亏损订单明细保持原顺序生成；A列使用动态整列XLOOKUP并保留公式，必须无N/A。

四、负责人
读取 ${LOCAL_PATH_041}，并以该配置中的全部门店为负责人覆盖清单。自${REFERENCE_DATE_003}运行起，新增示例门店〈67〉、示例门店〈65〉、示例门店〈44〉、示例门店〈50〉、示例门店〈59〉、示例门店〈39〉、示例门店〈37〉、示例门店〈28〉、示例门店〈14〉9家门店，负责人均强制为角色02；原有覆盖继续有效。按规范化完整名称或相同门店编码处理，不得重复编码。Sheet2不得存在角色05或角色06，原对应门店分别为角色03、角色04。

五、独立汇总
同目录生成汇总MMDD.xlsx，单Sheet“汇总”，固定14列：门店id、门店名称、全部订单数、订单成本合计、商品原价合计、商品成本率、全部线上毛利合计、全部单均毛利、美团订单数、美团线上毛利合计、美团单均毛利、饿了么订单数、饿了么线上毛利合计、饿了么单均毛利。订单成本使用财务源“成本”；数量按渠道内去重订单号统计，全部渠道包含所有渠道。

自${REFERENCE_DATE_014}运行起执行最新毛利口径：全部线上毛利合计=源数据全部线上毛利+0.6×去重美团订单数；美团线上毛利合计=源数据美团线上毛利+0.6×去重美团订单数；美团单均毛利不加0.6，按“源数据美团线上毛利÷美团订单数”计算，等价于“美团线上毛利合计-0.6×美团订单数”后除以美团订单数。全部单均毛利仍按调整后的全部线上毛利合计÷全部订单数；饿了么不调整；其他规则不变。F、H、K、N列全部数据行及合计行保留Excel公式。

六、核验与报告
核对两源日期一致、7个Sheet顺序及隐藏状态、亏损商品范围、Sheet1逐行映射、动态公式、缓存值、日期、长编号、排除门店、汇总金额；至少逐Sheet视觉检查。成功报告目标日期、两原始文件名、7个Sheet行数、收入“-”删除数、排除前后门店/订单数和各排除门店订单数、汇总门店数、全部/美团/饿了么/其他订单数、负责人覆盖配置命中数及各命中门店订单数、两个最终路径。

七、看板
仅在主流程全部通过后运行 ${LOCAL_PATH_042} project\loss_portrait_dashboard\update_dashboard.ps1。失败时保留报表和原始文件并单独报告。飞书上传暂停，不要自动上传。
