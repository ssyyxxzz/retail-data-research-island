# 牵牛花必有品每日监控

- 原配置状态：暂停
- 调度时间：05:00（Asia/Shanghai），准确规则以配置为准。
- 模板默认状态：暂停，不注册、不执行任务。
- 配置：[automation.example.toml](automation.example.toml)

## 流程正文（脱敏）

每天早上 05:00 在这个固定聊天中执行牵牛花必有品监控全流程，不要新建聊天。工作目录为 ${LOCAL_PATH_003}。必须使用已登录的隔离 Google Chrome，远程调试端口为 9223；不得绕过登录。若端口不存在，使用 ${LOCAL_PATH_004} 启动；若端口存在但 CDP WebSocket 无响应，只重启 9223 对应的隔离浏览器进程后再试。若登录失效，在本聊天明确提示需要用户登录。

门店范围固定读取 ${LOCAL_PATH_046}：按每行“渠道名”和“渠道门店状态”的相同序号配对，保留渠道名包含“美团”且对应渠道门店状态严格等于“营业中”的门店；另外无论美团渠道状态如何，固定额外加入门店编码 ${BUSINESS_IDENTIFIER_012} 示例零售门店（示例门店〈66〉）、${BUSINESS_IDENTIFIER_013} 示例零售门店（示例门店〈68〉）、${BUSINESS_IDENTIFIER_014} 示例零售门店（示例门店〈24〉）。所有门店的总部状态非空时必须为“启用”。当前监控范围应为 93 家。不得再使用旧的 ${LOCAL_PATH_047} 作为门店范围。

神价固定读取 ${LOCAL_PATH_048} 的 Sheet1“主档对应sku”整列，忽略 Sheet4；热销固定读取 ${LOCAL_PATH_049} 的“热销”Sheet“sku”整列。全部非空值去重，严禁只查询一个 SKU。

下载步骤：下载由Windows定时任务调用牵牛花接口执行，不再逐页点击。后台隔离9223仅承载已登录会话和平台签名，不切换用户正在使用的浏览器。先检查本地接口记录和实际Excel；正在运行时等待同一个程序完成，不另起重复进程或重复提交导出。没有当日有效来源且程序未运行时，执行下列本地入口；失败明确报告，不改回页面操作。只接受运行日创建的任务及通过字段、日期、SKU和门店范围校验的文件，禁止用历史分析成品替代原始数据。 Windows任务QNH-Independent-API-monitor，入口 ${LOCAL_PATH_018} -Group monitor；兼容入口${LOCAL_PATH_050}。程序先运行daily_prepare_skus.py，再以神价、热销完整SKU清单分别查询和导出，动态校验全部字段及渠道库存，保存${LOCAL_PATH_051}；同名旧文件留档。下载记录${LOCAL_PATH_052}。平台生成可能耗时10—20分钟，复用当日任务并等待，不重复提交。

3. 下载完成后运行 ${LOCAL_PATH_053}。脚本已配置为从 ${LOCAL_PATH_046} 动态筛选美团渠道营业中门店并固定加入示例门店〈67〉、示例门店〈65〉、示例门店〈22〉三店，写入 ${LOCAL_PATH_054}。若当天结果已存在，先移到 ${LOCAL_PATH_055}。
4. 运行 ${LOCAL_PATH_056}，确认两份下载文件非空并包含“门店商品”Sheet，结果包含“商品情况明细”和“门店汇总”，当前门店汇总应为 93 家且无公式错误。

接口失败说明具体原因并保留已下载文件。每次报告监控门店数、神价/热销SKU数、接口查询数量、两笔任务成功/失败数量、匹配组合数、异常统计及最终文件路径。
