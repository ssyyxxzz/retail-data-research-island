# 淘闪每日下载昨日报表

- 原配置状态：启用
- 调度时间：07:00（Asia/Shanghai），准确规则以配置为准。
- 模板默认状态：暂停，不注册、不执行任务。
- 配置：[automation.example.toml](automation.example.toml)

## 流程正文（脱敏）

每天北京时间早上7点，下载前一天（Asia/Shanghai）的淘宝闪购报表。只连接用户已登录的Chrome调试端口9224，后台地址${SERVICE_URL_004}，账号应为示例运营主体。调用数据下载中心接口，导出店铺活动、红包活动、商品活动（按店铺明细、全部字段）以及流量转化（按店铺明细、整体数据、按筛选时间汇总、全部5项指标）。日期动态取昨天，开始与结束日期相同。所有报表、ZIP、下载记录和校验文件只保存到${LOCAL_PATH_028}，不存C盘。优先执行node ${LOCAL_PATH_029} YYYY-MM-DD）；若端口9224未启动、登录失效或导出失败，准确说明阻塞原因，不声称完成。已存在且校验成功的昨日文件直接复用，避免重复创建任务；已有RUNNING任务须继续等待，不重复提交。下载后核对任务SUCCESS、大小、XLSX有效性和表内日期，打包四表。仅在成功完成新一日下载、失败或需要用户操作时通知，状态无变化或重复检查时保持安静。
