## 占位符

- `${SERVICE_URL_*}`：平台或内部数据服务入口。
- `${LOCAL_PATH_*}` / `${EXECUTABLE_*}`：工作目录、文件或程序位置。
- `${MESSAGE_ID_*}`：机器人配置、收件人或群标识。
- `${BUSINESS_IDENTIFIER_*}`：门店编码等业务标识。
- `${REFERENCE_DATE_*}`：历史规则生效日期或基准日期。
- `${CREDENTIAL_*}` / `${EMAIL_*}`：凭据或邮箱。

不提供占位符与真实值的对应表。真实门店、人员与企业名称已改成统一别名。调度时间读取 RRULE；若历史名称或正文中的时间不同，应在部署前统一配置。

## 范围

本仓库提供流程说明和配置模板，不包含依赖脚本的内部实现、Excel、数据库、浏览器资料、登录状态、通知回执或任何发送能力。不会因为推送 GitHub 而运行任务。
