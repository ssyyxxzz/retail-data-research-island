# 零售数据研究岛 / Retail Data Research Island

一个以晨光海岛插画为地图、通过角色探索七个研究空间的网页概念。

**此仓库是独立公开演示版。全部门店、商品、订单、金额、流程状态与导出内容均为虚构数据。** 不包含真实业务报表、人员信息、任务回执、内部服务地址或数据库凭据。

## 运行

在本目录运行 `python -m http.server 8080`，打开 `http://localhost:8080/`。也可将目录部署至支持静态网站的服务，支持子目录部署。

## 交互

- 点击“登岛”，开始柔和背景音乐；右下角可静音。
- 点击地面或使用 WASD / 方向键移动，靠近地标按 E 进入。
- 七个空间涵盖经营观测、门店实验、商品库存、活动策略、亏损订单、商品关联和成长档案。
- 示例看板支持门店和周期筛选、示例 CSV 导出。
- 商品清单工具支持本机导入 CSV、TSV、XLSX，文件不上传。
- 配送与折扣模拟采用虚构曲线；拖拽查询使用内存中的虚构数据，不连接数据库。

## 公开版本范围

只导出了白名单中的界面代码、原创视觉与音频、以及重新构造的演示数据。真实看板快照、历史文件、业务脚本、自动化配置和消息发送记录未进入此仓库或 Git 历史。

生产环境需要独立的数据服务、访问控制及数据库配置；本演示不含平台调价、自动下载或消息发送能力。
